[[urn-gb]]
= GB URN schemes

This file is the single home of the GB (`gb`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:gb:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:gb:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 10 ids, 0 round-trip, 0 reshape, 10 do not re-parse, 0 raise, 0 empty, 1 colliding URNs.

Corpus: 10 of 10 pass ids parse.
