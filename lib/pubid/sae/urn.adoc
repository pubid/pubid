= SAE URN schemes

This file is the single home of the SAE (`sae`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:sae:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:sae:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn`: not audited (no fixture directory under the registry name).
