[[urn-bsi_pfs]]
= BSI PFS URN schemes

This file is the single home of the BSI PFS (`bsi_pfs`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

The PFS-compiled module-composition flavor of bsi (pubid/pubid#706 §4 —
the first module-composition proof flavor, `definitions/bsi.pfs` in
pubid-grammar). The composed definition declares the scheme-canonical
tags with a narrowed atom table (`pub-`, `part-`, `year-`, the adopted
node and the consolidated `ids`), registered under the `bsi_pfs` flavor
key. to_pubid_urn emits and round-trips on every absorbed face: the
plain BS face, the composed consolidated bundles and the PAS
designation, and the adoption wrappers — the codec composes nested
nodes root-first along the wrapper's uniform `base` slot (the declared
`adopted.attribute: base`), so an adoption encodes the origin
document's chain under the wrapper's type token
(`BS EN 1073-2:2002` → `urn:pubid:bsi:cencenelec.en:1073:part-2:year-2002:aen`).
Its literal corpus is the parity harness's absorbed faces
(`spec/pubid/bsi_pfs/`).

The declared schema carries a type row per composed family. The
standalone-amendment row (pubid-grammar#151, the face-only designation)
places `sa` over a positional `number` core: `AMD 11015` encodes
`urn:pubid:bsi:sa:11015`, the same row-driven placement every other
type uses.
