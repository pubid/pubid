[[urn-cen_cenelec]]
= CEN/CENELEC URN schemes

This file is the single home of the CEN/CENELEC (`cen_cenelec`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:cencenelec:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:cen_cenelec:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 192 ids, 89 round-trip, 69 reshape, 34 do not re-parse, 0 raise, 0 empty, 0 colliding URNs.

Atoms, canonical order: `pub-` (`publisher`), `co-` (`copublishers`, list), `part-` (`part`), `year-` (`year`), `month-` (`month`), `v-` (`version`), `stage-` (`stage`).

Nested identifiers: `adopted-(…)` (`adopted`, id), `ids-(…)` (`identifiers`, ids).

Nested identifiers of other flavors (written with their own schema, qualified token `<flavor>.<token>`): `iec`, `iso`.

*Partial schema* (`lib/pubid/cen_cenelec/pubid_urn_schema.rb`), landed with
GOST, for the types a GOST adoption can name: `en`, `aen`, `amd`, `cor`,
`consol`, `tr` and `ts`. It declares the atom order above plus `adopted-` and
`ids-`. An absent atom writes nothing, so the CEN wave can add types and
atoms without changing these URNs, as long as the relative order of these
atoms stays. `aen` and `consol` have no core: an adopted EN keeps its number
on the `adopted` document, and a consolidated identifier has only its
`identifiers`
(`urn:pubid:cencenelec:consol:ids-(cencenelec:en:14988:year-2017),(cencenelec:amd:1:year-2020)`).

*Landed (issue #670)* — the wave declares the remaining types (`cr`,
`cwa`, the two harmonization documents, `ep`, `es`, `fragment`, `guide`,
plus the `base` and `id` tokens) and adds `subpart-` (between `part-` and
`year-`, a placement no GOST-nested row can see) and the nested-date atoms
`dateyear-`/`datemonth-` after `month-`. The GOST wave's URNs encode
identically. All 189 corpus rows emit.

The "open" shapes of the partial schema, resolved: an EN with a month
serializes `"date" => {year, month}` and carries `dateyear-`/`datemonth-`
now; `subpart` has its atom. An EN whose stage is not in the registry
keeps nested `type`/`typed_stage` (CEN's `compact_hash` declines) — no
parse makes that shape today, so it stays unplaced and keeps raising
"does not place" instead of a silent drop.
