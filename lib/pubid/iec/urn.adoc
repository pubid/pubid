[[urn-iec]]
= IEC URN schemes

This file is the single home of the IEC (`iec`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Partial schema landed with the IEEE wave: only `pubid:iec:international-standard` (`is`), which IEEE ids nest. The GOST wave added `amd`, `consol` (no core; its members ride `ids-`), `tr` and `ts`, which GOST adoptions can name, and the `ids-` atom at the end of the atom order.

Namespace: `urn:pubid:iec:` (the `_type` flavor segment).

Official URN: none in the IANA registry. pubid emits the RFC 5141-style `urn:iec:std:…`; keep it as the IEC render form.

Current `to_urn` (≤400 sampled pass ids): 400 ids, 249 round-trip, 71 reshape, 6 do not re-parse, 0 raise, 74 empty, 0 colliding URNs.

Corpus: 12331 of 12331 pass ids parse.

Atoms, canonical order: `pub-` (`publisher`), `co-` (`copublishers`, list), `part-` (`part`), `subpart-` (`subpart`), `year-` (`year`), `month-` (`month`), `ed-` (`edition`), `lang-` (`languages.*.code`, list), `database-` (`database`, bool), `fragmentnumber-` (`fragment_number`), `sheetnumber-` (`sheet_number`), `sheetyear-` (`sheet_year`), `undated-` (`undated`, bool), `vap-` (`vap`, list), `tc-` (`technical_committee`), `wdlang-` (`wd_language`), `wdstage-` (`wd_stage`), `wpstage-` (`wp_stage`), `wptype-` (`wp_type`).

Nested identifiers: `ids-(…)` (`identifiers`, ids), `cispr-(…)` (`cispr_identifier`, id).

*Landed (issue #670)* — the wave declares all 26 types and keeps every
earlier wave's atom in its place (`database` moves to the bool the corpus
serializes, before any URN carried it; `frag-`/`sheet-`/`sheetyear-`/`vap-`
sit after `database`, before `lang-`, whose landed URNs never move). All
12,330 corpus rows emit. The wave inherited two identity gaps exactly as
`to_hash` had them (pinned in `lib/pubid/iec/CLAUDE.md`): a
WorkingDocument serialized only `_type`, so its URN was `urn:pubid:iec:wd`
and all 2,350 WD rows shared that one hash — a shared hash, not a collision;
and a TestReportForm's CISPR document sat in the unserialized
`cispr_identifier`. A wrapper also repeated its base's `month`/`day`/`undated`
at the top level, in the hash and so in the URN (`…:vi:month-10:…`); that
leak is closed (the date keys map on `SingleIdentifier`, see
`lib/pubid/iec/CLAUDE.md`), and no fixture URN moved.

*Closed (issue #687)* — the two gaps are gone: the working document's
committee, language, stage and work-programme stage/type serialize, the
document number sits in the positional core, and a CISPR-bearing
TestReportForm nests its document under `cispr-` (the form stays `#root` —
a TRF is about the CISPR document, not a wrapper of it). The new atoms sit
after `vap-` and before `lang-`, so no landed URN moves; the working
document goes from the shared type-only form to one URN per document
(`urn:pubid:iec:wd:2457:tc-1:wdstage-FDIS`).

Facet candidates (spelling-only): `languages.*.original_code`.
