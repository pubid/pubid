[[urn-idf]]
= IDF URN schemes

This file is the single home of the IDF (`idf`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:idf:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:idf:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 67 ids, 11 round-trip, 47 reshape, 9 do not re-parse, 0 raise, 0 empty, 0 colliding URNs.

Corpus: 67 of 67 pass ids parse.

Atoms, canonical order: `pubbody-` (`publisher.body`), `typeabbr-` (`type.abbr`), `typename-` (`type.name`), `typetypecode-` (`type.type_code`), `part-` (`part`), `year-` (`year`), `stageabbr-` (`stage.abbr`), `stageharmonizedstages-` (`stage.harmonized_stages`), `stagename-` (`stage.name`), `stagestagecode-` (`stage.stage_code`), `typedstageabbr-` (`typed_stage.abbr`), `typedstage-` (`typed_stage.code`), `typedstageharmonizedstages-` (`typed_stage.harmonized_stages`), `typedstagelongabbr-` (`typed_stage.long_abbr`), `typedstagename-` (`typed_stage.name`), `typedstageshortabbr-` (`typed_stage.short_abbr`), `typedstagestagecode-` (`typed_stage.stage_code`), `typedstagetypecode-` (`typed_stage.type_code`).

Landed (issue #670), with `typed_stage.abbr` a list (the stage's abbreviation array) — the same correction as BSI. The URNs run long, because `type`, `stage` and `typed_stage` serialize every registry field (the NIST ruling). All 65 corpus rows emit.

Finding: `to_hash` serializes the internals of a component (`type`, `stage`, `typed_stage`). Reduce it to the identifying value first (the ISO `Components::Code` precedent), or the URN carries registry data.
