[[urn-wmo]]
= WMO URN schemes

This file is the single home of the WMO (`wmo`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:wmo:` (the `_type` flavor segment).

Official URN: `urn:mrn:wmo:pub:…`, WMO's assigning authority of the IANA-registered `mrn` namespace, following the IALA pattern (pubid#763 proposed form; no authoritative WMO `urn:mrn:wmo:` rule is published — the S-411 repository carries none — so this shape is the namespace's extension until one exists).

Current `to_urn` (≤400 sampled pass ids): 58 ids, 58 round-trip, 0 reshape, 0 do not re-parse, 0 raise, 0 empty, 15 colliding URNs (the corpus' alternate spellings of the same documents — each distinct document has one URN).

Corpus: 58 of 58 pass ids parse.

Atoms, canonical order: `series-` (`series`), `vol-` (`volume`), `ed-` (`edition`), `status-` (`edition_status`), `updated-` (`updated_in`), `annexform-` (`annex_form`), `letter-` (`letter`).

Landed (pubid#763) as drafted; widened with the volume, series, status and updated-in atoms. The edition is one atom: the calendar-year face on a publication (`ed-2025`; the year pair escapes its slash as `ed-2021~2F2018`), the dotted face on a standard or annex (`ed-1.2.1`). `series` is nil on the WMO-No. default, so every pre-widening URN is unchanged.
