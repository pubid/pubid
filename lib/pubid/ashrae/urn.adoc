[[urn-ashrae]]
= ASHRAE URN schemes

This file is the single home of the ASHRAE (`ashrae`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:ashrae:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:ashrae:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 400 ids, 42 round-trip, 352 reshape, 6 do not re-parse, 0 raise, 0 empty, 0 colliding URNs.

Corpus: 2103 of 2103 pass ids parse.
