[[urn-iso]]
= ISO URN schemes

This file is the single home of the ISO (`iso`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:iso:`. Schema: `lib/pubid/iso/pubid_urn_schema.rb`.

Official URN: `urn:iso:std:…`, IANA-registered, RFC 5141. Current `to_urn`:
400 ids, 72 round-trip, 326 reshape, 2 do not re-parse, 8 colliding URNs.

pubid scheme: all 7,647 pass ids emit, round-trip by `to_hash`, are
path-safe, and give no collision.

Core: `number`. Atoms, canonical order: `pub-`, `co-` (list), `part-`,
`subpart-`, `year-`, `month-`, `day-`, `undated-` (bool), `ed-`
(`edition.number`), `stage-`, `iter-` (`stage_iteration`), `v-`
(`supplement_version`), `lang-` (`languages.*.code`, list), `loc-`;
`tcdoc` adds `tctype-`, `tc-`, `sctype-`, `sc-`, `wgtype-`, `wg-`; `dir`
adds `subgroup-`; `all` adds `ids-(…)`; `bundle` adds `sups-(…)`. Facets:
`langsrc` (`languages.*.original_code`), `edsrc` (`edition.original_text`).
