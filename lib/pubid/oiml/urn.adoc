[[urn-oiml]]
= OIML URN schemes

This file is the single home of the OIML (`oiml`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:oiml:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:oiml:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 105 ids, 3 round-trip, 96 reshape, 6 do not re-parse, 0 raise, 0 empty, 6 colliding URNs.

Corpus: 105 of 105 pass ids parse.
