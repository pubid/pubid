= EASC URN schemes

This file is the single home of the EASC (`easc`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

Namespace: `urn:pubid:easc:` (the `_type` flavor segment).

Official URN: none. The organization has no namespace in the IANA registry, and the current `urn:easc:…` form of `to_urn` is pubid-invented (legacy, no round-trip promise).

Current `to_urn` (≤400 sampled pass ids): 167 ids, 167 round-trip, 0 reshape, 0 do not re-parse, 0 raise, 0 empty, 0 colliding URNs.
