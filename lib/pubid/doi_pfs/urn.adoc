[[urn-doi_pfs]]
= DOI PFS URN schemes

This file is the single home of the DOI PFS (`doi_pfs`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

The PFS-compiled dev alias of doi (pubid#706): the same scheme, compiled
from `pubid-grammar`'s `definitions/doi.pfs` and registered beside the
coded flavor. It carries the SCHEME's canonical `_type` tag
(`pubid:doi:resource`) and the scheme's `to_urn` namespace (`doi`), so
its pubid-scheme URNs are byte-identical with the coded flavor's and
encode through the `[[urn-doi]]` schema above. Its own schema registers
under this key (same atoms, same shape), so a future cutover changes no
URN.

|===
| `_type` | token | core | ids | example
| `pubid:doi_pfs:identifier` | `id` | — | 0 | —
| `pubid:doi_pfs:resource` | `resource` | — | 4 | `doi:10.1000/182`
