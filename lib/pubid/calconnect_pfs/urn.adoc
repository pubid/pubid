[[urn-calconnect_pfs]]
= CalConnect PFS URN schemes

This file is the single home of the CalConnect PFS (`calconnect_pfs`) flavor's URN
documentation — the per-flavor split of the former `docs/URN-SCHEMES.adoc`
(owner ruling 2026-11-25: "for URN schemes how can we mix up different
flavors in 1 file? SPLIT THE FILE!"). The index that links every flavor's
file is `docs/URN-SCHEMES.adoc`.

The PFS-compiled dev alias of calconnect (pubid/pubid#706 §8 — the
acceptance port). The definition declares the scheme-canonical schema:
same atoms, tokens and core as [[urn-calconnect]], registered under the
`calconnect_pfs` flavor key, so `to_pubid_urn` stays byte-identical with
the coded flavor. Its literal corpus is the parity harness's faces
(`spec/pubid/calconnect_pfs/`).
